03Risk Register

Blocking

Golden drift by accident

cmd/io-surface/testdata/lint-*.golden

Lint output is byte-pinned. Any message or ordering change during review silently breaks go test ./cmd/io-surface.

Fix Goldens re-generate ONLY via an explicit, justified -update run; otherwise a golden failure is a review finding, not noise.
Important

Facts freshness after I/O-adding edits

docs/architecture/io-surface/facts.cue

The repo gates itself. Any new I/O call added while fixing findings turns CI red until init --force refreshes facts.

Fix Re-run go run ./cmd/io-surface check --root . after every fix batch; refresh facts when it asks.
Important

Taxonomy freeze

internal/scaffold/schema.cue · internal/manifest · internal/capability

Families, disciplines, and capability names exist in frozen, byte-identical copies. A review must never widen them — that is a schema-v1.3 session (TODO #136), owner-gated.

Nice to have

Verschlimmbessern guard

every proposed edit

No speculative rewrites. A fix ships only when findings stay identical or the improvement is provable (tests + goldens).
