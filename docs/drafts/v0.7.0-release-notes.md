The run-metadata release: per-run SARIF facts land ONCE in the run-level propertyBag.

- **Changed:** with go-finding v1.16.0's new run propertyBag (LarsArtmann/go-finding#53), the enforcement posture (`go-finding/meta/enforcement`) and the detector rule descriptions (`go-finding/meta/ruleDescriptions`, one map keyed by rule ID) ride `runs[0].properties` instead of being copied onto every result — N results × 2 unchanged values becomes one run bag. Consumers reading the per-result keys must move to the run bag; `positionOf`/`anchorFor` behavior is unchanged.
